# Machine Learning Algorithms: Mathematics & Python

Welcome to my Machine Learning learning journey!

This repository documents my daily exploration of the **mathematical intuition behind Machine Learning algorithms and their implementation in Python**.

My objective is to understand not just how to use an algorithm, but also:
- Why does the algorithm work?
- What mathematical concepts are behind it?
- How are its equations derived?
- How does it learn from data?
- Can I implement its core logic from scratch using Python?

## My Learning Approach

For every algorithm, I aim to cover:

1. **Intuition:** Understand the algorithm through simple explanations and real-world examples.
2. **Mathematics:** Break down mathematical equations and derivations step by step.
3. **Numerical Examples:** Solve problems manually to understand the calculations.
4. **Python Implementation:** Implement the algorithm from scratch using Python.
5. **Practical Understanding:** Explore applications, assumptions, advantages and limitations.
